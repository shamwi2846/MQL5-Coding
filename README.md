# MQL5-Coding

A small skill for Claude Code and Codex that helps write, review, compile and smoke-test MetaTrader 5 (MQL5) code on Windows. It checks MQL5 facts in the installed [MQL5 CHM MCP](https://github.com/shamwi2846/MQL5-CHM-MCP) first, compiles with MetaEditor, and runs one Strategy Tester smoke test with safety gates around saved accounts and running terminals.

**Status:** design stage. Read the design in [docs/design.md](docs/design.md). No skill code yet.

This is version 2 of the `mql5-coding` skill, rewritten to be small. Version 1 (v1.2.10) remains in [MQL5-Coding-Skill](https://github.com/shamwi2846/MQL5-Coding-Skill).
